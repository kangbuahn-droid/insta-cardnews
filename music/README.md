# 릴스 배경음악 폴더

**비워둬도 됩니다.** 폴더에 곡이 없으면 프로그램이 분위기에 맞는 곡을 게시물마다 새로 작곡해서 깔아요(자체 제작이라 저작권 걱정 없음).
직접 고른 곡을 쓰고 싶은 분위기만 아래 폴더에 넣으면 그 곡이 우선 쓰입니다.

AI가 기사마다 분위기를 정하고, 아래 폴더에서 곡을 하나 무작위로 골라 릴스에 깝니다.

| 폴더 | 분위기 | 어울리는 기사 |
| --- | --- | --- |
| `upbeat/` | 밝고 경쾌함 | 신기한 신기능, 반가운 소식 |
| `calm/` | 차분함 | 정보, 사용 팁 |
| `serious/` | 진지함 | 규제, 사회적 영향, 논란 |
| `tense/` | 긴장감 | 사고, 위험, 경쟁 격화 |

- 폴더마다 3~5곡 넣으면 반복이 덜 티 납니다. mp3, m4a, wav 지원.
- 비어 있는 분위기 폴더는 자동 작곡 곡을 씁니다. `.env` 에 `MUSIC_SOURCE=folder` 면 다른 폴더 곡을, `MUSIC_SOURCE=none` 이면 무음.
- **저작권 문제가 없는 곡만** 넣으세요: YouTube 오디오 보관함(저작자 표시 필요 없는 곡), Pixabay Music 등.
